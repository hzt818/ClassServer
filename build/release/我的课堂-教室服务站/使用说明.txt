我的课堂 MYClassroom（ClassServer·教室服务站）使用说明
========================================================

一、这是什么
    教室服务站是"我的课堂"的网页端教学服务，与 Windows 大屏主程序、
    移动端遥控器互补：师生在浏览器里即可使用课堂聊天、作文 AI 批改、
    课堂传屏、文件共享和语音通话，教师无需安装任何客户端。
    本程序为单个 exe 自包含（页面模板/静态资源/SQLite 引擎已内嵌）。

二、快速开始（3 步）
    1.【重要】先把整个文件夹复制到目标位置（如桌面或 D 盘），
       不要在发布包原始目录里直接运行！
    2. 双击 ClassServer.exe（首次运行自动完成：建库、生成证书）
    3. 程序会自动打开浏览器进入登录页；也可以在局域网其它设备上访问
       https://<教师机IP>:8900/login （必须带 https:// 前缀）
    4. 教师先注册自己的账号，学生在登录页自助注册或由教师导入

    启动失败常见原因：
    · 端口 8900 被占用（可能已有另一个教室服务站实例在运行，或其它
      程序占用了该端口）：先在任务管理器结束 ClassServer.exe，再重试；
      或修改 config.properties 中的 app.port 换一个端口。
    · 程序会弹出中文错误框说明具体原因；如未弹出，请查看控制台窗口输出。

三、账户说明（默认不预置任何调试账户）
    · 教师：在登录页"注册"自助开通（支持支付宝实名核验；未配置支付宝
      密钥时可在 config.properties 打开 alipay.mock=true 仅限本地调试）。
    · 学生：登录页自助注册，或教师在"账号管理"页批量创建。
    · 需要批量测试账号时：把 config.properties 中 app.seed_demo_accounts
      改为 true 后重启一次，会创建 admin01~admin10（教师）与
      u001~u100（学生），随机初始密码清单在 data\initial_accounts.txt
      （仅教师本机；分发后建议删除该文件，并改回 false）。

四、核心功能
    · 聊天室：房间制群聊、@提醒、消息撤回、表情反应、AI 助手
      （@AI 提问 / @AI+图片 识图 / 发送"画：xxx" AI 文生图）
    · 作文批改（语文/英语应用文/读后续写）：
      - 拍照/上传 → OCR 识别 → AI 批改（批改温度滑块：越低越严格、
        越高越自由），逐维度对照官方评分标准"先定档再给分"
      - 名师点评 + 升华建议、教师逐篇短评（可空）、AI 图片批注
        （红=错误/绿=好句/橙=可提升）+ 手写风格分数章
      - 教师批阅流水线：逐篇复核、标为优秀、改成绩；优秀作文页供
        全班学习；学生管理统计（篇数/均分/优秀数）
      - 导出：Word（docx）与 PDF 批改报告（含原文对照、批注图、
        名师点评、基础/进阶修改版）、Excel 成绩表
    · 课堂传屏：教师把屏幕实时传给全体学生（双画质自适应，教室
      Wi-Fi 约 60 人流畅）；录屏（含系统声音+麦克风）保存为 webm
    · 上课模式：右下角"上课"按钮把界面收成可拖动圆点，画笔
      （6 色 3 粗细）/像素橡皮/长按清屏，随时最大化且批注保留
    · 文件管理：上传下载、公开/私有/群组权限、回收站恢复
    · 语音：语音消息（可 AI 转文字）、房间内语音通话（WebRTC）

五、配置文件（config.properties）
    app.port      监听端口，默认 8900（与主程序 WebSocket 8899 不冲突）
    qwen.api_key  通义千问 DashScope API Key（AI 批改/OCR/聊天助手/
                  传屏录屏之外的核心 AI 能力都依赖它；未配置时相关
                  功能会提示未配置，其余功能不受影响）
    qwen.grading_concurrency  同时批改的作文数上限，默认 6（1~16）
    app.seed_demo_accounts    调试账户预置开关，默认 false
    db.path       SQLite 数据库文件位置，默认 ./data/classroom.db
    jwt.secret    登录令牌密钥（留空时首次启动自动生成并写回本文件）
    运行后程序会把本机专属配置（如自动生成的 jwt.secret、你填写的
    qwen.api_key 等）写入该文件——这些内容只应留在教师本机，切勿把
    运行过的文件夹再拷贝分发给别人！分发的发布包始终使用空白模板。

六、数据与安全
    · 全部数据保存在本目录：data\（数据库）、static\uploads\（作文与
      批注图等）、certs\（自签名 HTTPS 证书，IP 变化后自动重新生成）
    · 首次访问或换 IP 后浏览器会提示证书不受信任，点"高级 → 继续前往"即可
    · 局域网访问不通时，请在 Windows 防火墙入站规则中放行 8900 端口
    · 180 天前的批改记录、已删除文件和语音消息会自动清理

七、界面外观
    · 暖色羊皮纸视觉 + 液态玻璃悬浮层（Lora 衬线标题 + Poppins 正文）
    · 侧栏底部「外观」按钮可切换：跟随系统 / 浅色 / 深色（自动记忆）
    · 手机浏览器访问自动切换为底部玻璃标签栏，适配刘海屏安全区

八、常见问题
    · 启动后一闪而过：查看同目录是否已生成 data\；端口被占用时修改
      config.properties 的 app.port 后重试
    · 手机/其它电脑访问不了：检查教师机与设备是否在同一局域网、
      防火墙是否放行 8900 端口
    · AI 相关功能报"未配置"：在 config.properties 填入有效的 qwen.api_key
    · 导出的 PDF 中文乱码/报错：PDF 依赖系统字体（如
      C:\Windows\Fonts\simhei.ttf，Windows 自带）；个别精简系统缺失
      时请补装字体，或改用 docx 导出
    · 传屏/录屏按钮无反应：浏览器需 HTTPS 安全上下文（本服务默认
      自签名 HTTPS）；在浏览器弹窗中选择"整个屏幕"效果最佳
